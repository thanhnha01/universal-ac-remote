stored as docs/SupportedProtocols.upstream.md. `tools/generate_protocol_catalog.py`
extracts all detailed A/C family rows and identifies uncompiled/unhandled
protocol IDs against IRac::isProtocolSupported(); it does not auto-enable code.
The generated report is docs/PROTOCOL_CATALOG.md.

SWIGLIB adapter delta: local changes to IRac.cpp reset a carrier-frequency
capture vector; local changes to IRsend.cpp append normalized Hz values in
enableIROut(). JNI rejects mixed-frequency transmissions rather than guessing.

outputStr() assertion for LG A/C raw state 0x8808721 (On, Cool, 22C, Medium,
38000 Hz). Generic instrumentation smoke tests also traverse Gree, Panasonic,
Daikin, Fujitsu, Midea, Mitsubishi A/C, and Samsung A/C through IRac::sendAc.

IRac.cpp, IRsend.h, IRremoteESP8266.h, and per-protocol headers.
